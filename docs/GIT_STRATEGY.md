# Git/GitHub Strategy

Use small Conventional Commits from the first day.

Examples:
- `feat(auth): add student registration`
- `feat(tasks): add task model`
- `feat(agent): add get tasks tool`
- `fix(auth): validate login flow`
- `docs(srs): add RBAC matrix`

Recommended branches:
- `main` — stable
- `develop` — integration
- `feature/auth`
- `feature/tasks`
- `feature/agent`

Open Issues for work items and PRs for completed features. Avoid one huge final upload.
